# Hyperion flagship design harvest ledger

Status: reviewed pattern source, not a runtime dependency list.

## Adopted principles

- Product outcome and next action appear before architecture language.
- Every cinematic must move the visitor to a product decision, proof point, or bounded inquiry.
- Premium means controlled rhythm, material contrast, decisive type, useful motion, and honest system posture.
- Every animated surface requires a poster, reduced-motion behavior, data-saving behavior, and a defined request budget.
- Repeated components must share one visual grammar and one accessibility contract.
- Public proof is labeled by maturity and must never imply unnamed customer work.

## Harvest disposition

| Bucket | Use | Boundary |
| --- | --- | --- |
| UI/UX and anti-slop references | Composition, hierarchy, typography, interaction critique | Patterns are rewritten in Hyperion components; no wholesale code import |
| Motion and media references | Cinematic sequencing, purposeful activation, editorial transitions | No autoplay audio; one active cinematic; posters and fallbacks required |
| Diagram references | Build journey, authority, and lifecycle explanations | Diagrams remain public-safe and source-opaque |
| Playwright QA references | Responsive, keyboard, motion, and visual regression matrix | Development evidence only; no client or credential data |
| Marketing/SEO references | Human-first offer copy, route metadata, crawl parity | No invented traction, testimonials, or maturity claims |
| Large skill collections | Discovery registry only | Never installed wholesale into the production dependency graph |

## Release review checklist

1. Can a visitor name the offer and next action in five seconds?
2. Does every visual support a real choice or proof statement?
3. Is the motion optional, bounded, and quiet when the visitor asks?
4. Are demo people, companies, media, and contacts unmistakably fictional?
5. Are quote, payment, order, and fulfillment states truthful and receipt-backed?
6. Does keyboard, touch, reduced motion, and narrow-screen use preserve the journey?
