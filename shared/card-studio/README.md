# Card Studio public contracts

This folder is the canonical compiled-only contract boundary for Card Studio.
The browser may submit only schema-valid JSON documents and opaque asset
references. Binary artwork never travels through the intake or proposal feed.

The catalog is a versioned public estimate source. It does not become a quote,
charge a customer, or prove that a Shopify mapping is live. Founder Command
receives minimized proposal events and must use an explicit operator command to
advance any order projection.
