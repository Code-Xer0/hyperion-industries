# Agent policy sample

Illustrative excerpt only. A paid configuration is adapted to the buyer's declared repository, canonical policy location, authority owner, and selected agent environments.

## Authority

- Work only within the approved project scope.
- Ask the named human owner before consequential writes, external communication, deployment, payment, or publication.
- Preserve existing work and authoritative policy. Do not create a duplicate system.
- Stop when instructions conflict, authority is missing, or verification fails.

An instruction file guides agent behavior. Runtime permissions and approval controls must be configured in the agent environment itself.

## Completion

- Name the exact files changed and checks run.
- Report evidence, remaining uncertainty, and any action that still needs human approval.
